# Casino

Frontend-приложение на React, TypeScript и Vite.

## Локальный запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

## Проверка и production-сборка

```sh
npm run lint
npm run build
```

Production-файлы создаются в каталоге `dist/`. Для проверки локальной production-сборки выполните `npm run preview`.

## Деплой

Используйте Node.js 20.19+ или 22.12+ на этапе установки и сборки, установите зависимости командой `npm ci`, выполните `npm run build` и опубликуйте содержимое `dist/` как статический сайт.

Приложение использует `BrowserRouter`. Настройте веб-сервер или платформу статического хостинга так, чтобы запросы к клиентским маршрутам (например, `/profile` и `/games`) возвращали `index.html`, а существующие статические файлы отдавались напрямую. Без такого fallback главная страница откроется, но обновление или прямой переход на вложенный маршрут может вернуть 404.
