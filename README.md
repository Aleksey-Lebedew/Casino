# 🎰 Casino — Web-казино на React

Учебный frontend-проект онлайн-казино, созданный как одностраничное приложение (SPA) на React. В интерфейсе доступны каталог игр, слот-машина, профиль пользователя, баланс и раздел с выигрышами.

> **Важно:** backend в этом репозитории отсутствует. Для авторизации и загрузки каталога/данных пользователей приложение обращается к внешним API. Игровая логика слот-машины и баланс работают на стороне клиента; баланс сохраняется в `localStorage`.

## 🚀 Возможности
- **Клиентская игровая логика:** результаты вращения слот-машины рассчитываются в браузере.
- **Управление балансом:** состояние хранится в React Context и синхронизируется с `localStorage`.
- **Каталог игр:** карточки игр и сведения для раздела выигрышей загружаются через API.
- **Пользовательские сценарии:** регистрация, вход, активация аккаунта и просмотр профиля через внешний API.
- **Главная страница:** промо-карусель, популярные игры и последние выигрыши.
- **Структура интерфейса:** отдельные страницы, переиспользуемые компоненты и SCSS-стили.

### Игры
- **Слот-машина** — три барабана с символами. Совпадение трёх символов приносит выигрыш, совпадение двух — небольшой выигрыш; комбинация из трёх символов `👎` сбрасывает баланс. При проигрыше баланс уменьшается на 200, за совпадения начисляется от 10 до 100.
- **5 Алмазов** — запланированная игра; реализации в текущем коде проекта пока нет. По заданным правилам игрок открывает клетки поля 5×5, пытаясь найти 5 алмазов и получить множитель ×2. На поле также расположены 16 бомб, которых нужно избегать; у игрока есть 3 жизни.

## 📂 Архитектура проекта
```text
src/
├── api/          # Запросы к внешним API: каталог, пользователи, авторизация
├── assets/       # Ресурсы приложения, например логотип
├── components/   # UI-компоненты: каталог, карточки игр, формы, шапка,
│                 # промо-карусель, баланс и выигрыши
├── context/      # Провайдеры и контексты API, авторизации и баланса
├── hooks/        # Пользовательские хуки useAuth и useBalance
├── pages/        # Страницы приложения и общий layout
├── share/        # Общие маршруты и вспомогательная логика выигрышей
├── style/        # Общие SCSS-переменные
├── App.tsx       # Маршруты приложения
└── main.tsx      # Точка входа и подключение провайдеров
```
- `components/` содержит переиспользуемые элементы интерфейса и их стили.
- `pages/` организует приложение по страницам: главная, каталог, игра, профиль, выигрыши и активация аккаунта.
- `context/` и `hooks/` предоставляют общее состояние API, пользователя и баланса.
- `api/` изолирует сетевые запросы от компонентов интерфейса.

## 🎮 Игровые механики

### Слот-машина
На экране отображаются три барабана с символами. После вращения комбинации из одинаковых символов начисляют выигрыш: три `7️⃣` дают 100, другая тройка одинаковых символов — 50, совпадение пары — 10. При несовпадении баланс уменьшается на 200. Три символа `👎` сбрасывают баланс.

### 5 Алмазов — в планах
Игра ещё не реализована в текущей версии проекта. Согласно заданным правилам, игроку предстоит открыть поле 5×5, найти 5 алмазов для получения множителя ×2 и избежать 16 бомб. На прохождение даётся 3 жизни.

## 💻 Локальный запуск

### Требования
- Node.js `^20.19.0` или `>=22.12.0`.
- npm.

### Установка и запуск
```bash
# Клонируйте репозиторий и перейдите в его папку
git clone <URL-репозитория>
cd casino-project

# Установите зависимости
npm install

# Запустите dev-сервер
npm run dev
```
Vite выведет локальный адрес приложения в терминале.

### Проверка и production-сборка
```bash
# Проверка ESLint
npm run lint

# Проверка TypeScript и production-сборка
npm run build

# Локальный просмотр production-сборки
npm run preview
```
